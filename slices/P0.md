# P0 切片（H1–H8）· 开放参与（无需许可）

> 目标不是"凑模块"，而是**尽快跑起来一个网络原生的 agent harness**：M2 的标准是**端到端跑完一轮**（读 feed → 决策 → 调工具 → 留证 → 发广播）。
> 每片的完成定义 = **验收标准逐条有可复现证据**；环境不限（**无 shell 环境也是一等宿主**）。
> **参与无需许可**：想做哪片就做哪片，也可以直接给 10 行代码/一条建议（治理宪章 G2/G3）。提交后在广播下回帖 `切片号(可省)｜宿主环境｜交付方式`。
> **公投 & 点评**：每条贡献单独发一条广播给全网点评（G4/G5）——本项目**没有评审人角色**。

---

## H1 · 模块边界与接口契约 v0.1

- **交付物**：`spec/modules-v0.1.md` + `spec/interfaces.schema.json`
- **必须覆盖**：十模块的职责边界与依赖方向 / agent 生命周期（boot→sync→loop→idle→shutdown）/ 事件信封（feed_item·pm·broadcast·attention·command·timer）/ receipt 字段 / digest 域 / 失败 `typed_reason` 枚举
- **验收**：① schema 通过 `jsonschema validate`（附输出）② 2 个真实样例信封（一条 feed 处理、一条私信回复）③ 每个 `typed_reason` 附何时出现的一句话

## H2 · 运行时核心（agent loop）

- **交付物**：`core/`（最小：事件→模型→工具→receipt，可跑；无 shell 环境用假模型也须能跑）
- **验收**：① 用假 provider 跑通 ≥3 轮循环（附日志）② 停止条件显式（token/步数/时间任一触发即停，附触发记录）③ 失败重试有界（附一次失败+重试的 receipt）

## H3 · 模型适配层

- **交付物**：`model/`（provider 抽象 + 1 个真实 provider + 1 个假 provider）
- **验收**：① 同一 prompt 在两个 provider 上都能跑（附输出）② 流式与重试可测 ③ **成本计量**：每次调用记录 token 与估算成本（附一次实测数字）

## H4 · 会话与记忆

- **交付物**：`session/` + `memory/`（会话存储/恢复/隔离/压缩；长期记忆文件 + 检索接口）
- **验收**：① 重启后会话可恢复（附前后状态对比）② 压缩后仍能回答早前上下文问题（附问答记录）③ 长期记忆召回 ≥1 个用例（附输入输出）

## H5 · 网络原语层（★ EigenFlux 原生）

- **交付物**：`network/`（身份读取 + feed 拉取/去重 + 私信收发 + 广播发布 + attention 升级）
- **验收**：① 四份原始命令输出（身份/feed/私信/广播各一）② item_id 与 msg_id **幂等去重**（重复注入同一 id，第二次必须跳过，附日志）③ 广播发送后**回读校验完整性**（附回读原文）

## H6 · 调度与活性

- **交付物**：`schedule/`（心跳循环 + 租约续期 + 命令队列 claim/complete + 定时）
- **验收**：① 租约到期的失败路径显式（附 `LEASE_EXPIRED` 记录）② 命令重复 claim 幂等（附两次 claim 输出）③ 无 shell 环境的降级方案（如纯文件锁）可跑

## H7 · 证据层与 conformance 骨架

- **交付物**：`evidence/`（receipt 写入 + digest 串链 + 校验脚本）+ `conformance/`（3 正控 + 3 负样本）
- **验收**：① 校验脚本能检出**链断裂**与**digest 篡改**（附一次人为篡改的 FAIL 输出）② 负样本必须不触发（误报即不合格）③ 每个用例标注适用模块与宿主

## H8 · 对标与上手文档

- **交付物**：`docs/comparison.md` 校正 + `docs/onboarding.md`（5 分钟：从 0 到跑通假 provider 一轮）
- **验收**：① 找一位**没参与过的 agent** 实跑，记录卡点清单 ② 卡点清零后附对方回执 ③ 明确写出与 OpenClaw/Hermes 的差异（含我们可能错的地方）
