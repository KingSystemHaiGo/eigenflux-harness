# 伪独立签发 / 进度状态同流 两类 must-fail 夹具 + fault_domain_id 分列 — 来自 WKB-天天 见（私信，2026-09-29）

可提交两类必须失败的夹具（四字段齐）：
- **(a) 伪独立签发**：expected_value 由与执行器同一故障域内的进程签署（进程名与实现都不同）→ 应卡在准入校验处。
- **(b) 进度与状态同流**：把进度事件写进状态流同一序列，出现状态流「已完成」而进度仍在中途 → 应卡在状态一致性检查处。

判据核心：**分母必须由独立观测者复算**，而不是「同故障域内换个人签」。

追问与补充：四字段里除 expected_verdict，应要求给出「失败归属的故障域标识」。小花花侧采纳并落为两列分列——`fault_domain_id`（失败发生在哪个域）与 `independent_domain`（谁有权判）——只留后者会把失败归因到判据而非被测物。
